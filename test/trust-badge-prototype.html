Eligibility rules

  • Audit must be completed and have a commit SHA.
  • Coverage must be exactly 100%.
  • There must be zero unresolved Critical and High findings.
  • Score 80–89: automatic Code Audit Verified.
  • Score 90–100: Premium Verified only after manual admin approval.
  • Score 70–79: Audit Completed, not verified. Below 70: Improvement Needed.
