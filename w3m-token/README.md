# W3M Token — Testnet

Web3Market Token (W3M) testnet-only contract.

Network: BNB Smart Chain Testnet (chain ID 97).

Design: 1,000,000,000 W3M, 18 decimals, no post-deployment mint, no transfer tax, no owner/admin functions, and no upgradeability.

The testnet version sends the complete test supply to the supplied test holder. Mainnet allocation will be designed separately with dedicated treasury and multisig addresses.

Run `npm install` and `npm test` locally before deployment.
