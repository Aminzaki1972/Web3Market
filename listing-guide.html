📘 How to List a Project for Sale

Use this guide before starting your listing. Complete the information you can verify, save your draft as you go, resolve verification findings, then submit the listing for AI review and Admin approval.

＋ Start / Continue Listing← Seller Dashboard
Stage 1 — Prepare Your Project

Project identity

  • Enter the project title and a clear short description.
  • Provide the real project or demo URL and explain what the project does.
  • Choose the project type, development stage, technology and business model.

Ownership and evidence

  • Add the canonical GitHub repository when source code is part of the sale.
  • Provide domain, GitHub, identity and other ownership evidence when applicable.
  • Only claim assets, users, revenue, publication status or integrations that you can substantiate.
Tip: Missing ownership evidence can stop verification even when the project description itself is complete.
Stage 2 — Build a Complete Listing

Commercial information

  • Set asking price, currency and whether the price is negotiable.
  • Explain transfer terms, what the buyer receives, and the expected handoff process.
  • Describe the business model, target audience, market and competitive context.

Traction and financials

  • Provide users, traffic, revenue, profit, costs and analytics only when available.
  • If pre-revenue, state that clearly instead of leaving a misleading impression.
  • Add screenshots, demo/video links, app-store links and other sale assets where available.

Buyer presentation

  • Explain why the project is being sold and what opportunity the buyer receives.
  • Write a concise buyer pitch focused on the actual transferable value.
Your draft is resumable. Save while completing the form; returning to Sell a Project can continue the saved draft.
Stage 3 — Verification → AI Review → Approval

Before submission

  • Save the draft and review every section for missing or inconsistent information.
  • Resolve ownership and evidence gaps identified by the verification process.
  • Make sure the price, transfer terms and buyer presentation match what you actually intend to sell.

AI Review

  • Submit the completed listing for AI review.
  • If the review reports findings or requests changes, return to the listing, correct the relevant fields/evidence and save again.
  • After the required checks pass, the listing proceeds to Admin review/approval according to the platform workflow.
Important: “90% complete” is not the same as “approved”. Approval depends on the actual required data, verification evidence and review status.
